# Schedule Tasks

## WeeklySchedule

**責務(何をするのか)**

- 一週間のスケジュールを表示する。
- 個々のスケジュールの設定をする。

**表示(何を受け取り何を返すか)**

- ユーザー操作によってスケジュール設定に関する要素を受け取る。
- DisplayTimeSettingから変更イベントを受け取る。

**Props(必要な要素は何か)**

- WeeklySchedule
  - ScheduleList
    - ScheduleItem
      - ScheduleTimeBlock
  - ScheduleTimeLine
  - DisplayTimeSetting
  - MonthlyCalendar

**状態管理(自身か親か)**

- 個々のスケジュールの表示範囲
- スケジュールの登録状態
- 表示時間範囲

**依存関係(どのコンポーネントと連携するか)**

- ScheduleList
- ScheduleTimeLine
- DisplayTimeSetting
- MonthlyCalendar

**未決事項(将来の拡張や決定できないこと)**

- 各スケジュールの設定方法。フォーム入力が必要になる可能性がある。
- スケジュールをカレンダーに登録する方法。
- カレンダーから日付を選択した際に表示対象の週を変更する仕組みが必要。

## TaskSettings

**責務(何をするのか)**

- タスクの追加
- タスクの削除
- 登録中のタスクを表示する。

**表示(何を受け取り何を返すか)**

- AddTaskFormから入力されたタスクデータを受け取る。
- 登録済みのタスクデータをTaskListに渡して表示する。

**Props(必要な要素は何か)**

- TaskSettings
  - TaskList
    - TaskItem
  - AddTaskForm
    - Input
  - SettingButton

**状態管理(自身か親か)**

- 自身が状態管理する。
  - タスクの登録状態。

**依存関係(どのコンポーネントと連携するか)**

- TaskList
- AddTaskForm
- SettingButton

**未決事項(将来の拡張や決定できないこと)**

- 入力フォームをどのように表示するか。

## AddTaskForm

**責務(何をするのか)**

- タスクの入力フォームを表示する。
- 入力されたタスクデータを親に通知する。

**表示(何を受け取り何を返すか)**

- 未定

**Props(必要な要素は何か)**

- タスク登録イベント

**状態管理(自身か親か)**

- 未定

**依存関係(どのコンポーネントと連携するか)**

- TaskSettings
- Input

**未決事項(将来の拡張や決定できないこと)**

- 入力値を自身が管理するか、親から受け取るのかは実装時に検討。
