# Dashboard

## TodaysTasks

**責務(何をするのか)**

- 今日のタスクを表示する。
- 完了したタスクをプログレスバーに表示する。

**表示(何を受け取り何を返すか)**

- TaskSettingsから追加されたタスクを受け取り、チェックリストとして表示する。
- チェックボックスの完了状態に応じてプログレスバーを更新する。

**Props(必要な要素は何か)**

- TaskSettingsから受け取るタスクのデータ
- TodaysTasks内で構成されるコンポーネント
  - TaskList
  - TaskItem
  - TaskProgressBar

**状態管理(自身か親か)**

- タスクの完了状態を管理する。

**依存関係(どのコンポーネントと連携するか)**

- TaskSettings
- TaskList
- TaskItem
- TaskProgressBar

**未決事項(将来の拡張や決定できないこと)**

- プログレスバーの計算
- タスクの追加・削除に応じた達成率の変化をどのように反映するか。

- 将来的にはGoogle Calendarと連携したい。

## Pomodoro

**責務(何をするのか)**

- Pomodoroタイマー機能の集中時間、休憩時間、セット回数を表示する。
- 経過時間をプログレスバーに表示する。
- 開始と停止のボタンを表示する。
- 集中時間、休憩時間、セット回数の計測。
- 集中時間と休憩時間の切り替え。

**表示(何を受け取り何を返すか)**

- PomodoroSettingから集中時間、休憩時間、セット回数のデータを受け取る。
- データ反映し経過時間の表示やプログレスバーを表示する。

**Props(必要な要素は何か)**

- Pomodoro
  - FocusElapsedTime (集中時間の経過状況)
  - ShortBreakElapsedTime (休憩時間の経過状況)
  - CompleteSession (セット回数の完了状況)
  - ElapsedTimeBar
  - SettingButton

**状態管理(自身か親か)**

- 自身が状態管理をする。
- 経過時間
- タイマーの動作状況
- 現在のセット回数
- 休憩状態と集中状態の切り替え

**依存関係(どのコンポーネントと連携するか)**

- PomodoroSetting
- FocusElapsedTime
- ShortBreakElapsedTime
- CompleteSession
- ElapsedTimeBar
- SettingButton

**未決事項(将来の拡張や決定できないこと)**

- タイマーの挙動は実装に検討する。集中状態と休憩状態の切り替えなど。
- 時間の計測方法。現在時刻から計測するのか、タイムカウンターから計測するのか。
