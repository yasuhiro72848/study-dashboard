# Common Components

## Card

**責務(何をするのか)**

- 機能を表示するためのベース。
- 表示サイズ、余白、角丸などの共通スタイルを管理する。
- 表示する内容は親コンポーネントに委ねる。

**表示(何を受け取り何を返すか)**

- 親コンポーネントから要素を受け取る。
- 受け取った要素をCardに配置をして返す。

**Props(必要な要素は何か)**

- 機能によって調整が必要であるためスタイルは都度調整できるようにしている。

- children
- width
- height
- padding
- borderRadius

**状態管理(自身か親か)**

- Card自身が状態管理を行わない。
- 将来的にドラッグ操作やサイズ変更を実装する際に状態管理の責務を検討する。

**依存関係(どのコンポーネントと連携するか)**

- 親コンポーネントから表示する要素を受け取る。
- 特定の機能に依存せず、複数の機能で汎用的に使用する。

**未決事項(将来の拡張や決定できないこと)**

- ドラッグ操作による配置変更とサイズ変更の状態管理。
- それぞれの機能に応じたサイズや余白の設定方法。

## Input

**責務(何をするのか)**

- 入力に関連する共通コンポーネント
- 入力欄の共通スタイルを管理する。

**表示(何を受け取り何を返すか)**

- 親コンポーネントから要素を受け取り、入力欄を表示する。
- 入力された値を親コンポーネントに伝える。

**Props(必要な要素は何か)**

- 複数の入力形式を持つため、判別ユニオンでの管理を検討。
- number | text | date

- Props(利用する場所によってさらに追加する)
  - type
  - value
  - onChange

**状態管理(自身か親か)**

- 親コンポーネントが状態管理する。inputは入力値と変更処理を受け取る。

**依存関係(どのコンポーネントと連携するか)**

- Inputを利用する親コンポーネント
- 複数の親コンポーネントで汎用的に利用する。

**未決事項(将来の拡張や決定できないこと)**

- どこまで入力形式を共通化するかは実装時に考慮する。
- バリデーションエラーの対応。機能によって異なる可能性がある。

## SettingButton

**責務(何をするのか)**

- 設定や操作など親から渡されたイベントを実行する汎用コンポーネント

**表示(何を受け取り何を返すか)**

- 親コンポーネントから要素を受け取りイベントハンドラーを受け取る。
- 受け取ったイベントハンドラーを実行し戻り値は利用しない。

**Props(必要な要素は何か)**

- children
- onClick
- disabled

**状態管理(自身か親か)**

- 開始と停止、登録と解除などの状態は親が持つ。

**依存関係(どのコンポーネントと連携するか)**

- buttonを利用するすべてのコンポーネント
- 複数のコンポーネントで汎用的に利用する

**未決事項(将来の拡張や決定できないこと)**

- 共通スタイルは現状は親コンポーネントが受け持つ。共通のデザインがある場合に検討する。

## Checkbox

- ユーザーが選択した値を親コンポーネントに通知する。

**表示(何を受け取り何を返すか)**

- タスクの完了状態を受け取り、オンオフの状態を表示する。

**Props(必要な要素は何か)**

- checked
- onChange

**状態管理(自身か親か)**

- 完了状態は親コンポーネントが管理する。

**依存関係(どのコンポーネントと連携するか)**

- Today's Taskの親コンポーネントから使用する。

**未決事項(将来の拡張や決定できないこと)**

- 現状では、Today's Task以外で利用する機会がない。

## DateAndTime

**責務(何をするのか)**

- 今日の日付と時間のリアルタイム表示。

**表示(何を受け取り何を返すか)**

- Dateオブジェクトから現在日時を受け取り、最新の状態をリアルタイム表示する。

**Props(必要な要素は何か)**

- なし。

**状態管理(自身か親か)**

- 自身が最新の日時を状態管理する。

**依存関係(どのコンポーネントと連携するか)**

- 独立したコンポーネントとして実装。

**未決事項(将来の拡張や決定できないこと)**

- 将来的にはWeatherAPIと連携する予定。MVPが完成するまでは未実装。

## MonthlyCalendar

**責務(何をするのか)**

- 汎用の月間カレンダー。
- 年月と日付の選択を提供する。
- カレンダーの共通スタイルを管理する。

**表示(何を受け取り何を返すか)**

- 親コンポーネントから、保存の完了状態を受け取る。
- 保存状態を反映し表示する。

**Props(必要な要素は何か)**

- year
- month
- selectedDate
- onDateSelect

**状態管理(自身か親か)**

- 保存状態は親コンポーネントが管理する。

**依存関係(どのコンポーネントと連携するか)**

- ScheduleCalendar / ProgressCalendar の親コンポーネントから利用する。

**未決事項(将来の拡張や決定できないこと)**

- 将来的には、Google Calendar APIを利用する。スケジュールやプログレスの設計を考慮した上で判断したい。

## BaseBar

**責務(何をするのか)**

- 複数の進捗バーに共通するUIを表示するためのコンポーネント。
- バーの共通スタイルを管理する。

**表示(何を受け取り何を返すか)**

- 親コンポーネントから値を受け取り、バーの表示を変更する。
- 共通スタイルを適用したバーを表示する。

**Props(必要な要素は何か)**

未確定事項が多く現時点では決められない。

- BarColor
- BarSize
- Timer
- Counter

**状態管理(自身か親か)**

- 親コンポーネントが管理する。

**依存関係(どのコンポーネントと連携するか)**

複数のバーを表示するために以下の親コンポーネントがBaseBarを利用する。

- ProgressBar
- AchievementBar
- ElapsedTimeBar
- MediaBar

**未決事項(将来の拡張や決定できないこと)**

- 共通するPropsを判別ユニオンで管理できるか。
- 計算方法や値の違いをどのように判別するのか。
- 共通のスタイルはどこまで適用できるか。
