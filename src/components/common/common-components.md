# Common Components

## Card

- UIの表示は親コンポーネントの責務。Cardはサイズや余白、角丸など共通部分を持つ。
- 将来的にはドラッグ操作で配置とサイズの変更をしたいため状態管理が必要。しかし、親と子のどちらが責務を持つかは複数のコンポーネントを作成してから検討。
- dataの受け取り方は親コンポーネントから要素を受け取り、Cardコンポーネントに組み込む。
- サイズ変更や余白の設定は、機能によって調整が必要であるため、始めは自由に決められるようにする。
