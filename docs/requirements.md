# Study Dashboard 要件定義

## 1. 目的

毎日の学習に利用するツールをひとつのアプリに集約し、学習の管理や準備にかかる手間を効率化する。

## 2. 想定ユーザー

PCをメインデバイスとして学習を行う個人ユーザー

## 3. 利用シーン

・朝に一日のスケジュールを確認する。
・昨日の学習内容と今日の学習予定を把握する。
・ポモドーロタイマーを開始する。
・音楽を再生して学習に集中する。
・学習終了時に学習時間と進捗を記録する。
・一日の学習状況を確認する。

## 4. 必要な機能

・スケジュールカレンダー
一日、週間、月間の予定を確認できる。時間単位で管理できる。

・学習履歴
過去の学習内容や学習時間を確認する。

・今日のタスク
今日の学習予定を確認・構築する。前日に作成してもよい。
学習項目を具体的に決められる。

・ポモドーロタイマー
学習時間と休憩時間を設定できる。再生中の音楽に連動する。

・音楽再生
学習中の音楽再生。Spotifyなどの外部ツールと連携できる。

・学習時間と進捗の記録
学習終了時に学習時間や進捗、体調や達成感を記録。

・一日の学習状況を表示
その日の学習時間や進捗をまとめて確認できる。
翌日の学習履歴に活用する。

## 5. MVP

今回は自分が顧客であるため、自分が毎日の学習に利用するために最低限必要な機能をMVPとして実装する。

・スケジュールカレンダー (Today's schedule)
・今日のタスク (Today's tasks)
・ポモドーロタイマー (Pomodoro)
・音楽再生 (Music)
・学習時間と進捗 (Progress)
・一日の学習状況 (Study Log)

## 7. 今回は実装しない機能

個人の学習環境を効率化する目的であるため、コミュニケーション機能や共有機能は実装しない。

・チャット機能
・複数ユーザーとデータ共有（SNSも含む）

また、学習の管理・効率化ツールを1つのアプリに集約する目的との関連性が低い機能は実装しない。

・ノートアプリと連携
・電子書籍アプリと連携
・AIとの連携
