# Design Notes

## 2026-09-09

### Figmaでページのラフ案を作成。

・ダッシュボード、スケジュール・タスク、学習記録、ポモドーロ・音楽の４つのページを整理。
・現段階では詳細なUI設計は行わず全体の配置を検討。

## 2026-9-11

### ダッシュボードのUI

・学習用ツールであるため、落ち着きと安心感を意識したグリーンの配色を選択。
・メニューの項目が少ないため、サイドバーからヘッダーメニューに変更。
・学習情報をすぐに視認できるように、薄いグレーをカードにした。
・カードのタイトルにマスク処理を使用したデザインを試したが、ちらつきがあるため採用を見送りにした。
・将来的に背景画像を使用する可能性を考慮し、カードの色や透明度の調整は現状維持にしている。

## 2026-9-13

### ポモドーロタイマー/学習進捗のUI

・ポモドーロタイマーは直感的でシンプルなデザインに。
・Progressは学習の進捗をグラフで表示してみたが、何を表しているのかわかりづらいためDashboardでは使用しないことにした。グラフはStudy Logの統計情報に使えないか検討中。
・Progressのデザインは後日改めて検討する。
