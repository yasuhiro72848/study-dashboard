# 学習メモ

## データ構造の設計

- 保存するデータと、コンポーネントの状態管理は別で考える。
- データ構造を設計する上で、状態管理が必要な部分は考慮に入れず、コンポーネント設計に委ねる。
- 同じデータを複数の場所で持たずIDによる参照を利用する。
- すべての値をデータで保存するのではなく、計算から算出できるものは計算する。
- 保存するデータと一時的に使用するデータはStorageに保存すべきかを考える。
- データごとに責任範囲を明確にし、どのデータをどこで管理するかを決める。
- データ同士の関係性を整理し、どのデータを基準に取得・更新するかを明確にする。
- どのデータがその情報の保有者なのかを明確にし、管理する場所と利用する場所を分ける。
