# Test Design

## 目的

- アプリケーションの主要ロジックが、期待した実行結果を返すことを確認する。
- テスト対象の機能や振る舞いを整理する。
- コンポーネントの状態管理は対象にしない。

## テスト一覧

### Dashboard Page

**Today's tasks**

- 設定済みの今日のタスクが反映される。
- タスクを完了状態に変更できる。

**Today's schedule**

- 設定済みの今日のスケジュールが反映される。

**Progress**

- 現在の累計完了時間、目標時間、達成率が反映される。
- 目標時間を変更できる。

**Music**

- 設定された音楽の再生状態が反映される。
- 音楽の再生/停止/先送り/早戻しができる。

### Schedule / Tasks Page

**Weekly Schedule**

- 指定した日付にスケジュールの設定・変更ができる。
- 1日分のスケジュールをカレンダーに保存する。
- 1日分のスケジュールをカレンダーから呼び出す。

**Task Settings**

- タスクの追加と削除ができる。

### Study Log Page

**Weekly Progress**

- 週間の合計学習時間の計算
- 週間の平均学習時間の計算
- グラフ用の各日の平均学習時間の計算
- グラフ用の達成率をProgressHistoryから取得する。
- グラフ用の各日の完了時間をProgressHistoryから取得する。

**Progress History**

- CurrentProgressから設定済みのgoalTimeを取得する。
- DailyProgressからgoalTimeを設定できる
- PomodoroからcompleteTimeを取得する。
- 完了時間と目標時間から達成率を計算する。
- 目標時間が変更された場合の達成率を再計算する。
- conditionを変更できる。
- historyMemoを変更できる。
- 一日の進捗データがカレンダーにあるならば更新する。
- 一日の進捗データがカレンダーにないならば追加する。
- 一日の進捗データをカレンダーから取得する。

### Pomodoro & Music Page

**Pomodoro Setting**

- Pomodoroの各種時間の設定と計算ができる。
- Pomodoroで使用する音楽を変更できる。

**Music player**

- MVPでは実装しない。

- 年月を変更できる。
- 日付を選択できる。

**DateAndTime**

**SettingsButton**

- 実装時に判断

**Card**

- カードのサイズを変更できる。
- カードの位置を移動できる。
- 実装時に判断

**Input**

- 入力フォームの編集と反映ができる。
- 実装時に判断

**Select**

- セレクトボックスの選択ができる。
- 実装時に判断

**BaseBar**

### 変更履歴 2026-10-04

**Today's Schedule**

セレクトボックスによる表示時間範囲の状態管理であるためコンポーネントテストにて実装することにした。

- 除外<br/>
  Today's schedule : タイムラインの表示時間が変更できる。

### 変更履歴 2026-10-05

**Pomodoro**

Pomodoroの型定義と仕様から見ても、タイマーの状態遷移を保証するテストであり、現時点で独立したデータ処理がなくテスト対象から除外した。<br/>

- 除外
  - 設定された時間とセッション数が進行状況に反映される。
  - タイマーの開始と停止ができる。

**Music**

Musicの型定義ではデータの処理がなく、状態管理とAudioAPIで構成されているためテスト対象から除外した。<br/>

- 除外
  - 設定された音楽の再生状態が反映される。
  - 音楽の再生/停止/先送り/早戻しができる。

**Weekly Schedule**

Weekly Scheduleのデータ処理は、指定した日付にスケジュールの設定と変更ができることをテスト対象とする。<br/>
一方で、カレンダーで選択した日付の表示やタイムラインの表示時間の変更は状態管理に該当するため除外した。<br/>
また、状態管理で扱うデータのうち、複数のスケジュールを日付ごとにまとめて管理する処理については、独立したデータ処理としてテスト対象にした<br/>

- 変更
  スケジュールの設定ができる。<br/>
  -> 指定した日付にスケジュールの設定・変更ができる。

- 除外
  - タイムラインの表示時間が変更できる。
  - カレンダーで選択した日付が反映される。

- 追加
  - 1日分のスケジュールをカレンダーに保存する。
  - 1日分のスケジュールをカレンダーから呼び出す。

### 変更履歴 2026-10-08

**Schedule Calendar**

UIの操作と状態管理のみのため、テストから除外した。<br/>

- 除外
  - スケジュール登録された日付を選択できる。
  - 月を変更できる。

**Weekly Progress**

指定された期間の、週間の進捗データを正しく計算するテストであり、
月と日付の変更は状態管理に該当するため除外した。
また、それぞれの進捗データの計算は複数に分けてテストすることにした。

- 除外
  - 月と日付の変更ができる

- 変更前
  - 週間の進捗データを計算する。

- 変更後
  - 週間の合計学習時間の計算
  - 週間の平均学習時間の計算
  - グラフ用の各日の平均学習時間の計算
  - グラフ用の達成率をProgressHistoryから取得する。
  - グラフ用の各日の完了時間をProgressHistoryから取得する。

### 変更履歴 2026-10-12

**Progress History**

進捗データの処理を複数のテストに分解した。また日付の選択は状態管理であり、MonthlyCalendarの責務となるためここではテストから除外した。<br/>

- 変更前
  - 進捗データの登録/削除/編集ができる。

- 変更後
  - CurrentProgressから設定済みのgoalTimeを取得する。
  - PomodoroからcompleteTimeを取得する。
  - 達成率を計算する。
  - conditionを変更できる。
  - historyMemoを変更できる。
  - 一日の進捗データをカレンダーに保存する。
  - 一日の進捗データをカレンダーから取得する。

- 除外
  - すべての日付が選択できる。

### 変更履歴 2026-10-14

**ProgressHistory**

CurrentProgressのデータ取得だけでは修正が効かないため、ProgressHistoryからgoalTimeの変更ができるように変更した。<br/>

- 追加
  - DailyProgressからgoalTimeを設定できる。

### 変更履歴 2026-10-15

**Progress History**

目標時間の変更をProgressHistoryからも変更できるため、達成率の計算を2つのテストに分けた。<br/>

- 変更前
  - 達成率を計算する。

- 変更後
  - 完了時間と目標時間から達成率を計算する。
  - 目標時間が変更された場合の達成率を再計算する。

### 変更履歴 2026-10-18

**Progress History**

進捗データを保存するテストは更新と追加の2種類が必要であるため変更した。<br/>

- 変更前
  - 一日の進捗データをカレンダーに保存する。

- 変更後
  - 一日の進捗データがカレンダーにあるならば更新する。
  - 一日の進捗データがカレンダーにないならば追加する。
