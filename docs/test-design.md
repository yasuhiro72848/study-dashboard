# Test Design

## 目的

- アプリケーションの主要ロジックが、期待した実行結果を返すことを確認する。
- テスト対象の機能や振る舞いを整理する。

## テスト一覧

### Dashboard Page

**Today's tasks**

- 設定済みの今日のタスクが反映される。
- タスクを完了状態に変更できる。

**Today's schedule**

- 設定済みの今日のスケジュールが反映される。

**Progress**

- 現在の累計完了時間、目標時間、達成率が反映される。
- 目標時間を変更できる。

**Music**

- 設定された音楽の再生状態が反映される。
- 音楽の再生/停止/先送り/早戻しができる。

### Schedule / Tasks Page

**Weekly Schedule**

- 指定した日付にスケジュールの設定・変更ができる。
- 1日分のスケジュールをカレンダーに保存する。
- 1日分のスケジュールをカレンダーから呼び出す。

**Task Settings**

- タスクの追加と削除ができる。

**Schedule Calendar**

- スケジュール登録された日付を選択できる。
- 月を変更できる。

### Study Log Page

**Weekly Progress**

- 月と日付の変更ができる。
- 週間の進捗データの計算と反映がされる。

**Progress History**

- すべての日付が選択できる。
- 進捗データの登録/削除/編集ができる。

### Pomodoro & Music Page

**Pomodoro Setting**

- Pomodoroの各種時間の設定と計算ができる。
- Pomodoroで使用する音楽を変更できる。

**Music player**

- MVPでは実装しない。

### Common

**MonthlyCalendar**

- 選択した年月のカレンダーを表示する。
- 年月を変更できる。
- 日付を選択できる。

**DateAndTime**

- 現在の日時の取得と反映をする

**SettingsButton**

- クリックイベントを親に通知する。
- 実装時に判断

**Card**

- カードのサイズを変更できる。
- カードの位置を移動できる。
- 実装時に判断

**Input**

- 入力フォームの編集と反映ができる。
- 実装時に判断

**Select**

- セレクトボックスの選択ができる。
- 実装時に判断

**BaseBar**

- 各種計算方法に応じたBarを表示できる。

### 変更履歴 2026-10-05

**Pomodoro**

Pomodoroの型定義と仕様から見ても、タイマーの状態遷移を保証するテストであり、現時点で独立したデータ処理がなくテスト対象から除外した。<br/>

- 除外
  - 設定された時間とセッション数が進行状況に反映される。
  - タイマーの開始と停止ができる。

**Music**

Musicの型定義ではデータの処理がなく、状態管理とAudioAPIで構成されているためテスト対象から除外した。<br/>

- 除外
  - 設定された音楽の再生状態が反映される。
  - 音楽の再生/停止/先送り/早戻しができる。

**Weekly Schedule**

Weekly Scheduleのデータ処理は、指定した日付にスケジュールの設定と変更ができることをテスト対象とする。<br/>
一方で、カレンダーで選択した日付の表示やタイムラインの表示時間の変更は状態管理に該当するため除外した。<br/>
また、状態管理で扱うデータのうち、複数のスケジュールを複数のスケジュールを日付ごとにまとめて管理する処理については、独立したデータ処理としてテスト対象にした<br/>

- 変更
  スケジュールの設定ができる。<br/>
  -> 指定した日付にスケジュールの設定・変更ができる。

- 除外
  - タイムラインの表示時間が変更できる。
  - カレンダーで選択した日付が反映される。

- 追加
  - 1日分のスケジュールをカレンダーに保存する。
  - 1日分のスケジュールをカレンダーから呼び出す。
